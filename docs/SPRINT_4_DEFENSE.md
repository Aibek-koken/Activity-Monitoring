# Sprint 4: краткая защита US-13–US-23

## Что показываем

> **Актуально на 2026-11-14:** Sprint 4 интегрирован в основной проект. Редактор проверяет PDF прямо в EasyLang, ставит пометки, возвращает версию с числом страниц или одобряет её. Недельная версия не завершает активность; финальная — завершает. Подробности: `docs/SPRINT_4_REWORK_REPORT.md`.

Sprint 4 связывает переводчика и главного редактора одним циклом проверки. Переводчик отправляет PDF/DOCX; редактор открывает PDF в приложении, ставит пометки, добавляет комментарии/замены и записывает одно решение. Если нужны исправления, переводчик видит замечания, учитывает страницы переделки и отправляет новую версию. Недельное одобрение не завершает задачу, финальное — завершает. Файлы, пометки и решения каждого цикла сохраняются отдельно.

**Где запускать:** Sprint 4 работает из основного проекта (`soe_202_proj`). Откройте `http://localhost:5173`; API работает на `http://localhost:8080`, PostgreSQL на `localhost:55432`. SQL требует миграции V5, V5.1 и V5.2. Для повторной подготовки данных запустите из корня проекта `python3 scripts/seed_sprint4_defense.py` при работающих API и Docker Compose.

**Демо-аккаунты:** `translator@easylang.local` (Maya), `editor@easylang.local` (Elias), пароль `Demo123!`. Используйте только локальную демо-БД. SQL-шпаргалка: `SPRINT_4_DEFENSE_QUERIES.sql`.

## Подготовка общего сценария

1. Готовые файлы для живых действий: `docs/demo/sprint4-original.pdf` и `docs/demo/sprint4-corrected.pdf`. Это разные действительные PDF с читаемым текстом.
2. Войдите как Elias: покажите `EL-S4-901` и `EL-S4-903` в **Open reviews**, скачайте PDF у `EL-S4-901`, сохраните оценку времени и покажите нагрузку.
3. Войдите как Maya: откройте `EL-S4-902`, покажите уведомление и замечание. Ближе к концу загрузите `sprint4-corrected.pdf` — появится цикл 2.
4. Снова войдите как Elias: откройте `EL-S4-903`, покажите обе версии и нажмите **Approve version**. Статус задачи станет `COMPLETED`. После каждого шага запустите нужный запрос из SQL-шпаргалки.

Если нужен полный сценарий **с первоначальной отправкой**, используйте `EL-2026-002`: сейчас она `IN_PROGRESS` без Review. Maya сохраняет недельный остаток `0`, нажимает **Finish translation**, затем загружает `sprint4-original.pdf` и нажимает **Submit for checking**. При другом состоянии задачи начните с новой активности.

## Порядок живого показа

1. **Chief Editor:** US-15, US-16, US-17, US-23 на `EL-S4-901`/`903`; затем US-18 — измените оценку у `901`.
2. **Translator:** US-13, US-20, US-21 на `EL-S4-902`; затем US-14 — загрузите исправленный PDF.
3. **Chief Editor:** US-19 и US-22 на `EL-S4-903`: покажите результаты циклов и одобрите цикл 2.

**Что сказать про границы:** EasyLang не редактирует текст файла внутри приложения: редактор проверяет скачанный документ, а система хранит версии, замечания, решение и статус. Проверка прав тоже серверная: чужой редактор и другой переводчик не должны получить чужой документ. Повторное решение по уже закрытому циклу должно быть отклонено.
